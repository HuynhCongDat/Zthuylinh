# Cập nhật game ghép từ

- Khi ghép đúng, hai thẻ biến mất ngay và các thẻ còn lại tự sắp lại vị trí.
- Số cặp đúng, điểm, đồng hồ, âm thanh, lịch sử và chọn N5/N4 giữ nguyên.
- Khi hết giờ, các thẻ còn lại chuyển đỏ.
- Cập nhật toàn bộ file lên thư mục gốc GitHub Pages; đặc biệt matching-game.js và service-worker.js.
