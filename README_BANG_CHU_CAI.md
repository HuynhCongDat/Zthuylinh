# Nâng cấp bảng chữ cái — v8

- Nhấn từng chữ Hiragana hoặc Katakana để nghe phát âm và xem 3 từ ví dụ với cách đọc, nghĩa tiếng Việt và nút nghe riêng.
- 46 chữ cơ bản mỗi bảng, 276 ví dụ (có thể có từ trùng giữa các bảng).
- Riêng を/ヲ và ん/ン không có 3 từ thông dụng bắt đầu bằng chữ đó; ứng dụng giải thích và dùng ví dụ có chứa chữ.
- Giữ nguyên dữ liệu học tập trong localStorage và các tính năng khác.
- Thay các file trong GitHub Pages và chờ triển khai; nếu thấy giao diện cũ, tải lại trang/xóa cache ứng dụng.
