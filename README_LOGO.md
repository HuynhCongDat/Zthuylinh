# Cập nhật logo Nihongo Quest

Đã thay 3 icon PWA bằng hình mèo do bạn cung cấp:
- `icons/icon-192.png`
- `icons/icon-512.png`
- `icons/apple-touch-icon.png`

Các tính năng học tiếng Nhật được giữ nguyên từ bản luyện viết và luyện nói v3. Service worker đã tăng phiên bản cache để nhận icon mới.

## Cập nhật GitHub Pages
1. Giải nén ZIP, tải nội dung **bên trong** lên thư mục gốc repo `Zthuylinh` (thay file cùng tên).
2. Đợi Actions có dấu tích xanh.
3. Nếu iPhone vẫn hiện icon cũ, xóa biểu tượng cũ khỏi màn hình chính rồi mở Safari vào trang GitHub Pages và chọn Chia sẻ → Thêm vào Màn hình chính.

Lưu ý: ảnh gốc 92×98 px nên icon 512×512 là ảnh được phóng lớn, có thể không sắc nét hoàn toàn.
