Nihongo Quest - phiên bản nâng cấp chấm viết và luyện nói

- Chấm viết: so sánh hình dạng chữ vẽ với glyph máy, chuẩn hóa kích thước, điểm tham khảo 0-100; KHÔNG xác minh thứ tự/hướng nét.
- Luyện nói: nhận dạng giọng nói nếu trình duyệt hỗ trợ; điểm dựa trên văn bản nhận dạng, KHÔNG phải điểm phát âm âm học.
- Ghi âm và nghe lại: dùng MediaRecorder/getUserMedia; trên iPhone cần HTTPS và cấp quyền microphone.
- Cập nhật GitHub: upload nội dung thư mục này vào gốc repository Zthuylinh, thay index.html và service-worker.js; chờ GitHub Pages triển khai.
- Nếu PWA hiện bản cũ: đóng mở lại, tải lại Safari, hoặc xóa shortcut và thêm lại.
